# Resi_Scanner

Aplikasi ini digunakan untuk melakukan scanning barcode resi kurir, 
mendeteksi duplikasi (double scan) pada hari yang sama secara real-time, 
serta mengeksport data hasil scan ke format Excel (.xlsx) dan PDF. 
Aplikasi mendukung multi-database kurir yang dapat ditambah secara dinamis.

Aplikasi ini menggunakan database lokal melalui sqlite, dengan beberapa tools sederhana.
Semua Dokumentasi tentan code ada dalam file app.py
